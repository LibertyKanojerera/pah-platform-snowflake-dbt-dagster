# ADR-014: GitHub Actions OIDC with immutable subject claims

## Status
Accepted 2026-10-30.

## Context
[The sub GitHub sent, the sub the policy expected, the error that named neither.]

## Decision
[Pin owner and repo numeric IDs. Why not wildcard: an abandoned repo name can
be re-registered by someone else; a numeric ID is never reissued. The change
is a security improvement that presents as a breakage.]

## Consequences
[Trust policy must be updated if the repo is ever recreated. CI fails loudly
rather than silently trusting the wrong repo, which is the correct trade.]
